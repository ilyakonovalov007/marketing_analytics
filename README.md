# Marketing Analytics — Telegram Attribution MVP

## О проекте

Проект создан на основе задачи хакатона «Аналитика вне SQL — Поступашки».

На момент анализа отсутствовала связь «реклама → пользователь → покупка», из-за чего было невозможно оценить эффективность рекламных размещений.

Бизнес-цель: получать данные, необходимые для оценки рекламных размещений и дальнейшего распределения маркетингового бюджета.

Бизнес-результат: создана система, связывающая путь клиента от рекламы до покупки с источником привлечения для оценки эффективности маркетинга и распределения бюджета

## Решение

После хакатона я самостоятельно реализовал MVP системы маркетингового трекинга в Telegram.

Система позволяет связать рекламное размещение с пользователем, заявкой и покупкой, а затем рассчитать основные маркетинговые метрики.

Основной сценарий:

рекламное размещение → tracking-ссылка → Telegram-пользователь → заявка → покупка → выручка / ROMI
