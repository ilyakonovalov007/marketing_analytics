# Marketing Analytics — Telegram Attribution MVP

## О проекте

Проект создан на основе задачи хакатона «Аналитика вне SQL — Поступашки».

На момент анализа отсутствовала связь «реклама → пользователь → покупка», из-за чего было невозможно оценить эффективность рекламных размещений.

Бизнес-цель: получать данные, необходимые для оценки рекламных размещений и дальнейшего распределения маркетингового бюджета.

Бизнес-результат: создана система, связывающая путь клиента от рекламы до покупки с источником привлечения для оценки эффективности маркетинга и распределения бюджета

## Решение

После хакатона я самостоятельно реализовал MVP системы маркетингового трекинга в Telegram.

Система позволяет связать рекламное размещение с пользователем, заявкой и покупкой, а затем рассчитать основные маркетинговые метрики.

Основной сценарий:

рекламное размещение → tracking-ссылка → Telegram-пользователь → заявка → покупка → выручка / ROMI

## Аналитическая часть

В рамках проекта был проведён EDA исторических данных продаж.

Были проанализированы:
- структура и качество данных;
- динамика продаж;
- покупатели и повторные покупки;
- состав потенциальных заказов;
- ограничения текущей модели данных.

Анализ показал, что исторические продажи не содержат информации об источнике привлечения клиента. Из-за этого невозможно связать выручку с конкретным рекламным размещением.

Для решения этой проблемы после хакатона был разработан MVP системы маркетингового трекинга, который начинает собирать недостающую цепочку данных: **рекламное размещение → пользователь → заявка → покупка**.

Пользователь переходит в бота по tracking-ссылке и оставляет заявку. Бот фиксирует источник привлечения и связывает его с данными лида для дальнейшей атрибуции и анализа эффективности рекламы.


## Что реализовано

- создание tracking-ссылок для рекламных размещений;
- определение источника перехода пользователя;
- сбор заявок через Telegram-бота;
- сохранение данных в SQLite;
- расчёт маркетинговых метрик, включая ROMI.

## Стек

**Backend:** Python, aiogram  
**Database:** SQLite  
**Analytics:** SQL, pandas, Jupyter

## Как запустить

Клонировать репозиторий и установить зависимости:

git clone https://github.com/ilyakonovalov007/marketing_analytics.git
cd marketing_analytics
pip install -r requirements.txt

Создать файл .env в корневой директории проекта:

BOT_TOKEN=your_telegram_bot_token

Запустить Telegram-бота:

python bot.py

Для работы бота потребуется собственный Telegram Bot Token.

Как использовать
Запустить link_generator.py и создать рекламное размещение.
Получить уникальную tracking-ссылку для размещения.
Перейти по ссылке в Telegram и открыть бота.
Оставить заявку через Telegram-бота.
Добавить тестовую покупку через payment_test.py.
Запустить analytics.py для расчёта маркетинговых метрик.

Ограничения MVP
Платежи в текущей версии являются синтетическими и используются для демонстрации полного цикла.
Исторические данные продаж не связаны с источниками рекламных размещений.
Атрибуция показывает связь источника с покупкой, но не доказывает причинный эффект рекламы.
Для production-решения необходима интеграция с реальными данными о платежах, рекламных расходах и пользовательских touchpoints.
